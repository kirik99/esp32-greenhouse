# Автоматизация теплицы на ESP32 🌿

Проект по созданию умной теплицы с использованием микроконтроллеров ESP32 и ESP32-S3. Разделён на несколько этапов (стадий), каждый из которых добавляет новый функционал.

## Структура проекта

### `stage1_esp32_check/`
Базовая проверка работоспособности платы ESP32. Простой скетч для тестирования прошивки и базового ввода-вывода.

### `stage2_BME280/`
Подключение датчика температуры, влажности и давления **BME280** по шине I2C.

### `stage3_WiFi/`
Настройка подключения ESP32 к Wi-Fi сети.
> **Важно:** Данные вашей сети (SSID и пароль) нужно прописать в файле `wifi_config.h` (создайте его на основе шаблона `wifi_config.example.h`). Сам `wifi_config.h` исключён из Git для безопасности.

### `stage4_DS18B20/`
Подключение водонепроницаемого датчика температуры **DS18B20** для измерения температуры субстрата (почвы). Работает по протоколу OneWire.

### `stage5_CO2_sensor/`
Работа с датчиком углекислого газа **MH-Z19** через UART.
- `/esp32` — скетч для классической платы ESP32.
- `/esp32s3` — скетч для платы ESP32-S3 (используются другие пины Serial).

### `stage6_camera/`
Подключение USB-камеры к ESP32-S3 через USB Host.
- `/firmware` — прошивка для ESP32-S3, которая инициализирует камеру, получает кадры в формате YUY2 и отправляет их в Serial порт (UART0) каждые 10 минут.
- `/pc_tools` — Python скрипт `save_photos.py`, который запускается на компьютере, слушает COM-порт, декодирует сырые кадры YUY2 в JPEG и автоматически сохраняет их в папку с изображениями.

## Библиотеки
Для работы некоторых модулей требуются внешние библиотеки, которые нужно установить через Менеджер библиотек Arduino IDE:
- `DallasTemperature` и `OneWire` (для DS18B20)
- Изменённая библиотека `ESP32_USB_STREAM` (для работы с USB камерой в режиме YUY2 на ESP32-S3)
