# Growbox Server Infrastructure (Docker / Home Server / VPS)

Готовая серверная инфраструктура для автоматизированного культивационного бокса Growbox IoT (*Pleurotus ostreatus*). Работает локально дома (Docker Desktop / Linux) и на любом удалённом сервере (VPS).

## Архитектура портов и маршрутизации (Всё через 80 и 443)

Для доступа извне (через проброс портов на домашнем роутере или фаервол VPS) наружу открываются **только 2 стандартных порта: 80 (HTTP) и 443 (HTTPS)**. Все остальные сервисы изолированы внутри Docker.

```
                     Внешний мир / Интернет
                                |
                   [ Порты 80 (HTTP) и 443 (HTTPS) ]
                                |
                                v
               +----------------------------------+
               |      Nginx Reverse Proxy         |
               |       (Порты 80 / 443)           |
               +----------------+-----------------+
                                |
         +----------------------+----------------------+
         |                      |                      |
         v                      v                      v
[ Web UI Dashboard ]   [ Bridge REST API ]   [ MQTT WebSockets ]
   / (index.html)            /api/*           /mqtt -> mosquitto:9001
                                |
               +----------------+-----------------+
               |                                  |
               v                                  v
    [ InfluxDB 2.7 ]                     [ Images Storage ]
 (sensor data & history)               (UVC Camera snapshots)

                       Локальная сеть Wi-Fi
                                |
                   [ ESP32-S3 Microcontroller ]
                                |
                                v
                    [ Mosquitto MQTT :1883 ]
```

### Преимущества такой схемы:
1. **Максимальная безопасность:** InfluxDB (`8086`), Bridge API (`3001`) и WebSockets (`9001`) заблокированы на внешнем интерфейсе и не торчат наружу.
2. **Один порт для всего веб-трафика:** Дашборд, снимки с камеры, управление климатом и живой поток телеметрии по WebSockets работают через единое защищённое соединение **HTTPS / WSS (порт 443)**.
3. **ESP32 на домашнем Wi-Fi:** Общается с брокером по легковесному протоколу MQTT (порт 1883) напрямую внутри домашней локальной сети без выхода в публичный интернет.

## 🔐 Безопасность и PIN-авторизация (Zero Secrets in Git)

Панель управления защищена PIN-кодом администратора:
* **Где настраивается PIN:** в файле `server/.env` через переменную `ADMIN_PIN=ваш_пин`.
* **Безопасность:** Файл `.env` добавлен в `.gitignore` и **никогда не попадает в Git**. В коде фронтенда (`index.html`) пароли и PIN-коды **полностью отсутствуют** — авторизация проверяется на бэкенде через эндпоинт `/api/auth/verify`.
* **Длительность сессии:** 15 минут после ввода PIN. По истечении таймера сессия блокируется автоматически.

## 🍄 3-фазный климат-контроль вешенки (*Pleurotus ostreatus*)

Мозг системы микроклимата работает в сервисе `growbox_bridge` (Node.js 24 LTS):

| Режим | Температура | Влажность | CO₂ / Вентиляция | Освещение |
|---|---|---|---|---|
| **1. Инкубация** (`incubation`) | Субстрат **23.0°C – 24.5°C** (ТЭН + обдув) | **74% – 82%** (фоновая) | Без продувки по CO₂ (до 15000 ppm). FAE: 45с каждые 3ч | **ВЫКЛ 24/7** (полная темнота) |
| **2. Инициация / Холодовой шок** (`pinning`) | Воздух **14.0°C – 16.5°C** (стимуляция примордиев) | Высокая **92% – 96%** | Цель ≤ 800-900 ppm (продувка при > 950 ppm). Адаптивный FAE 20 мин | **10ч день / 14ч ночь** (09:00–19:00 ВКЛ) |
| **3. Плодоношение** (`fruiting`) | Воздух **16.5°C – 19.5°C** (рост тел) | **85% – 90%** | Цель < 1000 ppm (продувка при > 1000 ppm). Циклический FAE 20 мин | **12ч день / 12ч ночь** (08:00–20:00 ВКЛ) |
| **4. Ручной** (`manual`) | Ручное управление | Ручное управление | Ручное управление кнопками | Аварийная термозащита субстрата активна |

### Интеллектуальные блокировки:
* **`MIST_LOCK_AFTER_FAN` (90 секунд):** Увлажнитель принудительно заблокирован во время работы вытяжки и 90 секунд после её выключения, чтобы туман не выдувался наружу.
* **Пост-продувка ТЭНа (45 секунд):** Вентилятор обдува радиатора ТЭНа продолжает крутиться 45 секунд после отключения нагревателя.
* **Anti-Chattering (30 секунд):** Защита реле и оборудования от циклического дребезга.
* **Ограничение продувки:** Непрерывная работа вентиляторов ограничена 5 минутами для защиты моторов.

## 🚀 Развертывание за 3 шага

### Шаг 1. Скопировать конфиг
```bash
cd server
cp .env.example .env
# При необходимости отредактируйте ADMIN_PIN и пароли в .env
```

### Шаг 2. Запуск контейнеров
```bash
docker compose up -d --build
```
*Docker автоматически соберет сервис моста на Node.js 24 LTS, сгенерирует SSL-сертификаты и запустит Nginx на портах 80 и 443.*

### Шаг 3. Доступ
* **Дашборд:** `https://localhost` (или внешний IP/домен вашего сервера)
* **API статуса микроклимата:** `https://localhost/api/climate`
