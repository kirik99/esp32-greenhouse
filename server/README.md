# Growbox Server Infrastructure (Docker / VPS)

Готовая серверная инфраструктура для Growbox IoT системы. Работает как локально (Docker Desktop / WSL), так и на любом удалённом сервере (VPS на Ubuntu / Debian / CentOS).

## Архитектура сервисов

```
[ ESP32-S3 ] (Wi-Fi)
     |
     +---> [ Mosquitto MQTT:1883 / MQTTS:8883 ] <---+
     |                                               |
     |                                            [ Bridge ] (Node.js)
     |                                               |
     |                                               +---> [ InfluxDB:8086 ]
     |                                               +---> [ images/*.jpg ]
     v                                               |
[ Nginx Proxy :80 ] <--------------------------------+
     |
     +---> [ Web Dashboard UI :80 ] (PIN Auth 2212)
     +---> [ /api/* Proxy -> Bridge:3001 ]
     +---> [ /mqtt Proxy -> Mosquitto:9001 (WebSockets) ]
```

## 🔐 Безопасность и PIN-авторизация в веб-интерфейсе

Панель управления защищена PIN-кодом администратора:
* **PIN по умолчанию:** `2212` (можно настроить в файле `server/index.html` константой `ADMIN_PIN`).
* **Защищённые действия:** переключение тумблеров реле, кнопка «Сделать фото прямо сейчас».
* **Длительность сессии:** 15 минут после успешного ввода PIN. По истечении таймера сессия блокируется автоматически.
* В шапке дашборда расположен индикатор со статусом доступа и таймером обратного отсчёта.

## 🔒 Защищённый MQTTS (TLS/SSL порт 8883)

Mosquitto поддерживает как обычный порт `1883`, так и зашифрованный `8883 (MQTTS)`.
SSL-сертификаты генерируются в `server/mosquitto/certs/`:
- `server.crt` — сертификат сервера;
- `server.key` — приватный ключ.

Для перегенерации сертификатов на VPS:
```bash
cd server/mosquitto/certs
openssl req -x509 -nodes -days 3650 -newkey rsa:2048 -keyout server.key -out server.crt -subj "/CN=growbox"
```

На стороне ESP32 в файле `growbox/wifi_config.h` достаточно выставить:
```cpp
#define USE_MQTTS 1      // 1 = MQTTS (8883, TLS), 0 = MQTT (1883, TCP)
#define MQTTS_PORT 8883
```

## 🍄 Оптимальный микроклимат для вешенок в контейнере 70 л

В веб-панель встроен селектор целевых профилей («Плодоношение» и «Инкубация») с подсказками по нормам:

| Параметр | Инкубация (15–20 дней) | Плодоношение (волны сбора) |
|---|---|---|
| **Температура воздуха** | 20 – 24 °C | 14 – 18 °C (прохлада для шляпок) |
| **Температура субстрата** | < 28 °C (перегрев убивает мицелий) | 14 – 18 °C |
| **Влажность воздуха (RH)** | 70 – 80 % | 85 – 90 % (до 95% для примордий) |
| **CO₂** | до 10 000 – 15 000 ppm (мицелий любит CO₂) | **< 900 – 1000 ppm** (главный фактор формы!) |
| **Освещение** | Полная темнота (0 лк) | 8 – 12 ч/день (500–1000 лк, синий спектр) |
| **Вентиляция (объём 70 л)**| Минимальная | **Импульсная**: по 30–60 сек каждые 15–30 мин |

> [!TIP]
> В малом объеме (70 литров) постоянная работа вентилятора мгновенно высушивает субстрат и примордии. Используйте циклическое импульсное включение вытяжки и ультразвукового увлажнителя.

## 🚨 Аварийная защита (Hardware & Software Failsafes)

Микроконтроллер ESP32 непрерывно (каждые 2 сек) валидирует показания датчиков:
1. **Перегрев воздуха $\ge 50^\circ\text{C}$ или субстрата $\ge 32^\circ\text{C}$**: немедленно отключает нагреватель (Relay 2), включает вытяжной вентилятор (Relay 5) и блокирует повторное включение нагревателя до остывания ниже $35^\circ\text{C}$.
2. **Переувлажнение $\ge 98\%$**: немедленно отключает увлажнитель (Relay 1) для предотвращения скопления конденсата и луж на дне бокса.
3. **Обрыв датчиков (`-999`)**: отключает нагревательный элемент и сигнализирует об аварии в топик `growbox/status`.
4. В веб-интерфейсе появляется пульсирующий тревожный баннер.

## Развертывание на VPS за 3 шага

### Шаг 1. Склонировать репозиторий на VPS
```bash
git clone https://github.com/kirik99/esp32-greenhouse.git
cd esp32-greenhouse/server
```

### Шаг 2. Запустить автоустановку
```bash
chmod +x deploy.sh
./deploy.sh
```
*Скрипт сам проверит Docker, создаст `.env` конфиг, выставит права на папки и поднимет все 4 контейнера.*

### Шаг 3. Настройка фаервола VPS (если включен UFW)
```bash
sudo ufw allow 22/tcp     # SSH
sudo ufw allow 80/tcp     # Web Dashboard & API
sudo ufw allow 1883/tcp   # MQTT Broker (для ESP32 без TLS)
sudo ufw allow 8883/tcp   # MQTTS Broker (для ESP32 с TLS)
```

## Настройка ESP32 для подключения к VPS

В файле прошивки `growbox/wifi_config.h` укажите внешний IP вашего VPS:
```cpp
#define WIFI_SSID "your_home_wifi"
#define WIFI_PASSWORD "your_password"
#define MQTT_HOST "YOUR_VPS_PUBLIC_IP"   // Например, "185.123.45.67"
#define MQTT_PORT 1883
#define USE_MQTTS 0                      // 1 для порта 8883 (MQTTS)
#define MQTTS_PORT 8883
```

## Конфигурация (.env)
Все параметры можно настроить в файле `.env`:
* `TZ` — часовой пояс (по умолчанию `Europe/Moscow`)
* `INFLUXDB_USER` / `INFLUXDB_PASSWORD` — логин и пароль в базу данных
* `INFLUXDB_TOKEN` — токен доступа к API InfluxDB
* `WEB_PORT` — порт веб-интерфейса (по умолчанию `80`)

## Полезные команды

* **Статус контейнеров:** `docker compose ps`
* **Логи моста (приём фото и датчиков):** `docker logs -f growbox_bridge`
* **Логи MQTT брокера:** `docker logs -f growbox_mosquitto`
* **Прослушать топики в реальном времени:**
  ```bash
  docker exec -it growbox_mosquitto mosquitto_sub -t "growbox/#" -v
  ```
* **Перезапустить всё:** `docker compose restart`
